# LangChain Experiments

A collection of AI agents and workflowsbuilt with LangChain to explore various capabilities and use cases.

## Available Applications/Agents

| Agent                                                    | Library               | Description                                                                                                      |
| -------------------------------------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------- |
| [Fact-Checker](simple-fact-checker/)                        | Deep Agents           | Verifies claim accuracy using web search and CRAAP test methodology                                              |
| [Python Docs RAG](python-docs-rag/)                         | LangChain + FAISS     | Retrieval-Augmented Generation system for Python documentation                                                   |
| [LangGraph Foundation Course](langchain-foundation-course/) | LangGraph + LangChain | Experiments regarding graph building, checkpointing, HITL, and map-reduce. Based on LangGraph Foundation course. |
