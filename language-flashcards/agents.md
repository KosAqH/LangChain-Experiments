## Code convention
- Use Langgraph for agent implementation.
- Use pydantic for validation of data.

## Coding agents
- Don't overcomplicate the code. Keep it simple and easy to understand.
- Use clear and descriptive variable names.
- Write comments to explain the purpose of the code and any complex logic.
- Be critical of your own code and look for ways to improve it. Don't be afraid to refactor and optimize your code.
- Be critical of user's instructions and ask for clarification if needed. Don't assume you understand the user's intent without confirming it.

## Project
- File `project.md` contains the project schema. Use it as a reference, instead of searching the codebase. Update this file by yourself if you add new features to the project. This file is the single source of truth for the project schema.
